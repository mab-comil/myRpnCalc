# RPN電卓（myRpnCalc）

業務で使うための、逆ポーランド記法（RPN）の電卓です。PWA なので、インストールしてオフラインで使えます。

**公開 URL: https://mab-comil.github.io/myRpnCalc/**

## 特徴

- **RPN（逆ポーランド記法）**: `100 Enter 200 ＋` のように、数値を入れてから演算キーを押します
- **外税・内税キー**: 税率は2組（初期値 10% と 8%）。税額の端数処理（切り捨て／四捨五入／切り上げ／丸めない）を選べます
- **誤差のない十進計算**: [big.js](https://github.com/MikeMcl/big.js) で計算するので、`0.1 + 0.2` は `0.3` になります
- **履歴**: 演算の直前のスタックと押したキーを、ロール紙のように1行ずつ残します（最大 1,000 行）
- **オフライン動作**: サーバーとの通信はありません。スタック・履歴・設定は端末内（localStorage）に保存され、次に起動したときに戻ります
- **スマートフォンと PC の両方に対応**: PC では物理キーボードとテンキーで操作できます
- **テーマ**: 自動（端末の設定に従う）／ライト／ダーク

## インストール

| 端末 | 手順 |
|---|---|
| Android（Chrome） | URL を開き、メニュー（︙）から「アプリをインストール」または「ホーム画面に追加」を選ぶ |
| iPhone / iPad（Safari） | URL を開き、共有ボタンから「ホーム画面に追加」を選ぶ |
| PC（Chrome / Edge） | アドレスバーの右側にあるインストールのアイコンを押す |

新しい版を公開すると、起動したときに裏で受け取り、その次の起動で切り替わります。

## 使い方

### 計算の例

| 操作 | 結果 |
|---|---|
| `100 Enter 200 ＋` | 300 |
| `12 Enter 3 ＋ 4 ✕` | 60（(12 + 3) × 4） |
| `1000 外10% ＋` | 1,100（税込金額） |
| `1100 内10% −` | 1,000（税抜金額） |

税キーを押すと、基準額がスタック1に、税額がスタック0に入ります。続けて `＋` で税込、`−` で税抜の金額になります。

### キー

| キー | 動作 |
|---|---|
| `Enter` | 入力中の数値をスタックに積む。何も入力していなければ、スタック1の値を複製する |
| `C` | 入力中の数値や計算結果を消す。何もないときに押すと、スタックをすべて消す（AC） |
| `⌫` | 入力中の数値を1文字消す |
| `＋/−` | 正負を切り替える |

### PC のキーボード

| キー | 機能 |
|---|---|
| `0`–`9`、`.`（テンキーを含む） | 数字・小数点 |
| `+` `-` `*` `/`（テンキーを含む） | 四則演算 |
| `Enter` | Enter |
| `Backspace` | ⌫ |
| `Esc` / `Delete` | C |
| `n` | ＋/− |
| `q` / `w` / `e` / `r` | 外税1 / 内税1 / 外税2 / 内税2 |

### 設定

履歴欄の右上にある歯車（⚙）から開きます。税率、税額の端数処理、小数の表示桁数、テーマを変えられます。履歴の消去もここから行います。

## 開発

Svelte 5 ＋ TypeScript ＋ Vite ＋ vite-plugin-pwa ＋ big.js ＋ Vitest で作っています。

```bash
npm install
npm run dev        # 開発サーバー
npm test           # 単体テスト
npm run check      # 型チェック
npm run build      # 本番ビルド（dist/）
npm run preview    # ビルド結果の確認（Service Worker を含む PWA の動作はこちらで確認する）
```

仕様の詳細は [設計仕様書.md](設計仕様書.md) にあります。

`main` ブランチに push すると、GitHub Actions がテスト・型チェック・ビルドを行い、GitHub Pages に公開します。
